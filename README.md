# IPL Analysis

Project Overview
--
Analyzed IPL match and ball-by-ball data using SQL to explore team performance, player statistics, scoring trends, venues, and toss outcomes across IPL seasons

Objective
--
To uncover meaningful insights from IPL data using SQL-based exploratory and player performance analysis.

Dataset
--
Source: Kaggle

Link: [ kaggle.com/datasets/patrickb1912/ipl-complete-dataset-20082020 ](https://www.kaggle.com/datasets/patrickb1912/ipl-complete-dataset-20082020)

Contains IPL match-level and ball-by-ball delivery data covering multiple IPL seasons, including information on teams, players, venues, toss decisions, match results, runs, and wickets

Project Workflow
--
- Download the dataset and analyze the data in SQL
- Standardize venue names and format date values
- Perform exploratory analysis on matches, teams, players, venues, and scoring
- Analyze toss decisions and their relationship with match outcomes
- Perform individual player performance analysis
- Answer business-style questions using SQL
- Identify key insights from the analysis

Analysis & Questions
--

Match & Team Analysis
--
1. How many matches were played in each IPL season?
2. How many teams participated in each season?
3. Which teams have the most wins?
4. Which venues have hosted the most IPL matches?

Scoring & Bowling Analysis
--
1. How have total runs changed across IPL seasons?
2. Who are the top run scorers?
3. Who are the top wicket takers?
4. Which bowlers have bowled the most dot balls?
5. Which players have won the most Player of the Match awards?
6. What are the highest team totals in a single innings?
7. Which matches recorded the highest innings scores?

Toss Analysis
--
1. Which teams have won the most tosses?
2. Do teams prefer batting or fielding after winning the toss?
3. Does winning the toss increase the probability of winning the match?
4. Is batting or fielding first more successful after winning the toss?

Player Performance Analysis
--
1. Which players have scored the most total runs?
2. Which players have faced the most balls?
3. Which players have played the most matches?
4. Which players have been dismissed the most?
5. Which players have the highest average runs?
6. Which players have the highest strike rates?

Key Insights
--
* Identified the most successful teams and highest-performing players across IPL seasons.
* Analyzed scoring and bowling trends using ball-by-ball data.
* Evaluated the relationship between toss decisions and match outcomes.
* Compared individual players using runs, matches, dismissals, average runs, and strike rate.
* Identified high-scoring matches, dominant venues, and major IPL performance trends.
